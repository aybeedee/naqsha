# Urban context data attribution and licence

The binary and JSON context assets in this directory are a processed database
derived from:

- Overture Maps Foundation buildings release 2026-08-19.0;
- Google Open Buildings;
- Microsoft Global ML Building Footprints; and
- OpenStreetMap contributors.

The building theme and processed context database are distributed under the
[Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Google Open Buildings source data is available under CC BY 4.0. Microsoft
Global ML Building Footprints and OpenStreetMap data are available under ODbL.

Required map attribution is displayed inside the viewer. See the
[Overture attribution guide](https://docs.overturemaps.org/attribution/) and
[OpenStreetMap copyright page](https://www.openstreetmap.org/copyright) for the
upstream notices. This notice covers the context data assets, not the Naqsha
source code.
